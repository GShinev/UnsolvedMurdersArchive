# Unsolved Murders Archive

## Project Description

**Unsolved Murders Archive** is an ASP.NET Core MVC web application dedicated to documenting unsolved murder cases from the 20th century and preserving the memory of their victims.

The project focuses not only on the crimes themselves, but also on the people whose lives were unexpectedly taken from them — who they were, the lives they lived, and the futures they left behind.

Each case presents information about the victim or victims, the known circumstances surrounding the crime, the investigation, available evidence, suspects, and theories. The cases included in the archive remain unsolved, meaning that no perpetrator has ultimately been convicted of the crime.

Unsolved cases often leave many unanswered questions. By presenting the known facts and the different directions explored during the investigations, the application allows readers to consider the available information and form their own interpretation of what may have happened.

The application is intended for adult users interested in true crime, criminal history, and unresolved murder cases.

Above all, the purpose of **Unsolved Murders Archive** is to help preserve the memory of the victims. Behind every unsolved case is a person whose name and story deserve to be remembered.
